# 뒷면 아르바이트 — BACKSIDE PART-TIMER

현대 도시를 배경으로 한 **도트 그래픽 횡스크롤 로그라이트 탐험 RPG**입니다.
월세에 쫓기는 주인공 *하람*은 수상한 구인 앱 "틈새"에서 **청명관리(주)**의 야간 알바를 구합니다.
일의 내용은 사람들이 너무 많이 믿어 버린 괴담 — **밈적 존재** — 가 자라난 현장에 들어가
세계의 **뒷면**을 넘나들며 정리하는 것. 알바를 거듭할수록 조직의 이면이 드러납니다.

## 실행 방법

빌드 과정이 없는 순수 HTML5 Canvas + JavaScript 게임입니다.

```bash
# 저장소 루트에서 아무 정적 서버나 실행
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 직접 열어도 동작하지만, 폰트 로딩을 위해 로컬 서버 실행을 권장합니다.
GitHub Pages에 그대로 올려도 됩니다. 터치 기기에서는 화면 버튼이 자동으로 표시됩니다.

## 조작법

| 키 | 동작 |
|---|---|
| ← → (A D) | 이동 — 같은 방향으로 계속 달리면 **질주** (속도 약 1.4배, 점프도 더 멀리) |
| Z / Space | 점프 (길게 누르면 높이 점프) |
| ↓ 길게 | 발판 아래로 내려가기 |
| X | 공격 — 박자 맞춰 3번이면 **3연타 콤보**(세 번째는 마무리 일격 1.6배). 구르기·질주 중이면 **돌진 베기** (1.4배) |
| X 길게 | **차지 강공격** (2단계, 무기마다 효과가 다름) — 장우산은 **가드**(펼치는 순간 막으면 패링, 탄은 되돌려 보냄) |
| 공중에서 ↓ + X | **내려찍기** — 곧장 떨어져 주변을 함께 친다 (높이 떨어질수록 강함) |
| **C** | **뒤집기** — 표면 ↔ 뒷면 전환 |
| ↑ (W / E) | 조사 · 상호작용 · 건물 들어가기 |
| V | 소모품 사용 (허브에서는 휴대폰) |
| Q 또는 ↓+V | 소모품 변경 |
| Shift / 방향키 두 번 | **구르기** — 무적 시간 동안 적·탄을 뚫고 지나간다. 공격 후딜도 끊을 수 있다 |
| 방향키 없이 Shift | **백스텝** — 보는 방향을 유지한 채 뒤로 빠진다 |
| Esc | 일시정지 (환경 설정 · 상태 효과 안내 포함) |

**게임패드**(표준 배치, Xbox 기준)도 연결하면 바로 쓸 수 있습니다:
왼쪽 스틱/십자키 이동 · A 점프/확인 · B 취소/구르기 · X 공격 · Y 뒤집기 · RB 소모품 사용 · LB 소모품 변경 · LT/RT 구르기 · Start 일시정지 · Select 휴대폰.
터치 화면에는 구르기 버튼(⇆)이 따로 있습니다.

**환경 설정**(타이틀 · 일시정지 · 휴대폰 설정 앱): 전체/음악/효과음 음량, 화면 흔들림(끔/약하게/보통),
**깜빡임·글리치 줄이기**(광과민성 배려 — 반전 섬광, 점멸, 화면 찢김, 노이즈 흔들림을 줄이고 수칙 이벤트의 점멸은 일정한 어둠과 문구로 대체), 글자 속도.

## 핵심 시스템

- **특수 의뢰 (v1.4)** — 2장부터 틈새 공고에 섞이고(보수 1.35배), 경비 반장 최씨의 서브 연작 4편으로도 이어진다.
  - **정전 복구**: 층 전체가 어둡다. 방마다 스위치(↑)를 켜면 그 방이 밝아지고 안의 존재가 빛에 탄다. 대신 꺼진 방의 무언가가 깨어난다.
    스위치를 모두 켠 뒤 분전반을 ↑ 길게 눌러 올려야 퇴근할 수 있다. 꺼진 방에서는 공포가 천천히 차오른다.
  - **암흑 작업**: 빛이 하나도 없다. 발소리·착지·공격·구르기 소리가 **파동**이 되어 닿은 벽의 윤곽을 잠깐 보여 준다.
    벽에 부딪히면 **진동**(게임패드 · 휴대폰)으로 벽이 느껴지고, ↑로 **손뼉**을 치면 멀리까지 보이지만 *귀 기울이는 것*이 소리 쪽으로 달려온다.
    ↓를 누른 채 걸으면 조용하다. 존재가 가까우면 심장 박동이 진동으로 전해진다. 차단기를 올려야 출구가 열린다.
  - **배웅**: 뒷면에서 길 잃은 아이를 찾아 손을 잡으면(↑), 아이가 내 발자취를 그대로 따라온다(표면/뒷면 전환까지).
    존재에게 닿으면 겁에 질려 멈추고, 너무 무서우면 처음 자리로 도망친다. 아이와 함께 입구로 돌아오면 퇴근.
  - **추격**: 현장에 들어서면 거대한 *청소부*가 깨어나 내 발자취를 따라온다. 뒤집어도 소용없고, 너무 떨어지면 빨라진다.
    붙잡히면 큰 피해 — 구르기로 뚫고 지나가면 아슬아슬 회피. 출구까지 달리면 퇴근.
  - **새 장소**: 한빛타워 17층(야근 빌딩, 「꺼지지 않는 17층」) · 지하 3층 기계실(「배관의 노크」). 새 존재 *귀 기울이는 것*(눈이 없고 소리만 쫓는다).
  - 업적 6개(외형 3종: 무음 작업복 · 야광 러너 · 야간 경비 제복) 추가, 환경 설정에 진동 켜기/끄기.

    소화기(근거리 분사 연사, 둔화·밀쳐내기), 야전삽(무겁고 느림, 내려찍기 +60%, 차지: 양쪽 충격파), 전기 충격봉(경직, 차지: 방전),
    전기 파리채(빠름, 같은 존재를 3번 맞히면 연쇄 번개).

- **빠른 기동 전투**: 구르기(무적) · 백스텝 · 질주 · 돌진 베기 · 내려찍기를 이어 붙여 싸웁니다.
  구르기 무적 중에 공격이 닿으면 **아슬아슬 회피** — 잠깐 세상이 반속으로 느려지고, 공포가 줄고, **집중**(다음 공격 확정 치명타)이 붙습니다.
  가시 같은 함정은 구르기로 피할 수 없고, 공중 대시는 「0호선 승차권」의 능력입니다. 결과 화면에 아슬아슬 회피 횟수가 기록됩니다.

- **표면 / 뒷면 이중 세계**: 모든 현장은 두 겹의 지형으로 되어 있습니다. 표면에만 있는 셔터, 뒷면에만 있는 살덩이 다리,
  뒷면에만 있는 가시와 벽을 오가며 길을 찾습니다. 뒷면에서는 **정신력(SAN)** 이 계속 줄고, 시야가 좁아지고, 밈적 존재들이 돌아다닙니다.

  - **말소** — 괴담의 핵이 된 보스를 쓰러뜨리기 (표면으로 도망치면 보스가 회복)
  - **안정화** — 균열 세 곳에 앵커를 설치하며 몰려오는 존재들을 막기

- **절차 생성 현장 (방 조각 맵)**: 9개 장소(아파트·편의점·지하철·학교·PC방·병원·찜질방·재개발 구역·청명 지점) × 위험도 1~5. 직접 설계한 방 템플릿 14종을 격자(최대 8×3)로 이어 붙여
  분기·위아래 층·막다른 비밀방이 있는 맵을 만듭니다. 생성할 때마다 걷기·점프·낙하·뒤집기 이동 모델로
  입구→목표·아티팩트·출구까지 실제로 갈 수 있는지 검사하고, 실패하면 다시 만듭니다.
  - **봉인문과 열쇠**: 막다른 방에 있는 열쇠를 가져와야 길이 열립니다.
  - **임시 앵커**: 맵 중간의 체크포인트. 쓰러지면 한 번 여기서 다시 일어납니다.
  - **미니맵**: 들른 방·목표 위치·봉인문 표시 (통신 교란 시 깨짐).
  - 위아래 방은 가운데 사다리로 이어지고, 발판 위에서 ↓를 길게 누르면 내려갑니다.
- **심층 탐사**: 3~5층짜리 다단계 현장. 층마다 새 맵이 생성되고, 균열 앞에서 쉬면서 *더 내려갈지 / 챙겨서 철수할지* 고릅니다.
  깊어질수록 위험도·공포·통신 교란이 오르고 보수 배율도 오릅니다. 쓰러지면 챙긴 것을 모두 잃습니다.
- **아티팩트 — 제출할까, 숨길까**
  - **제출**: 보수 + 신뢰(승급)
  - **은닉**: 의심도 상승. 옥탑방 은닉처에 보관했다가
    - **흡수** → 능력치/특수 능력(이단 점프, 대시, 이면 시야 …) 획득, 대신 **오염도** 상승
    - 편의점 뒷문의 **노을**에게 판매하거나 **진실 조각**과 교환
  - 의심도가 높으면 아침에 **감사**가 들이닥쳐 은닉처를 압수합니다.
- **마음 지도 (노드식 스킬트리)**: 임무·승급·보스 처치로 얻는 **마음 조각(SP)** 으로 노드를 해금합니다.
  중심 "하람"에서 다섯 갈래가 뻗어 나가고, 갈래마다 노드 모양이 다릅니다.
  | 갈래 | 모양 | 방향 |
  |---|---|---|
  | 공포 | 가시 별 | 공포가 높을수록·뒷면일수록 강해짐. 핵심 "광란"(패닉 중 공격력 +50%) |
  | 분노 | 불꽃 | 처치·피격으로 분노 중첩. 핵심 "폭주"(충격파) |
  | 망각 | 빈 육각형 | 정신력·공포·디버프 저항. 핵심 "백지"(패닉 면역) |
  | 의심 | 눈 | 치명타·문서·은닉. 핵심 "진실의 눈"(아티팩트 +1) |
  | 희망 | 해 | 회복·희망 버프. 핵심 "마지막 희망"(한 번 버티기) |

  이웃한 갈래 사이에는 혼합 노드 5개(광포·무아지경·냉정·확신·용기)가 있습니다. 총 40노드이며 청명관리에서 돈을 내고 초기화할 수 있습니다.
- **공포 · 버프/디버프**
  - **공포 수치(0~100)**: 뒷면에 있으면 쌓이고(적이 가까울수록, 보스전·정신력 저하 시 더 빨리) 표면에서 가라앉습니다.
  - 디버프: **겁먹음**(공포 50+, 정신력 소모 +25%·이동 -10%), **패닉**(공포 100, 5초간 몸이 제멋대로·뒤집기 불가·정신력 소모 2배),
    **침식**(정신력 지속 감소, 3중첩), **둔화**, **환각**(정신력 30% 미만, 받는 피해 +25%)
  - 버프: **희망**(공포 증가 절반·정신력 회복·공격력 +10%, 단서/앵커/아티팩트/목표 달성/캔커피로 획득), **분노**(중첩당 공격력 +8%), **부적**
  - 적마다 붙이는 상태 이상이 다릅니다 (잡음·전단지 → 침식, 손 → 둔화, 등 뒤의 사람 → 공포 급증, 보스별 고유 효과).
- **통신 교란 (신호 불량)**: 주인공의 HUD는 "뒤집개" 휴대폰 화면입니다. 읽지 않은 알림 떼, 위험도 4 이상 현장의 *전파 오염 구역*,
  일부 보스의 "신호 간섭" 패턴은 통신을 공격해 휴대폰이 거짓말을 하게 만듭니다.
  - 체력·정신력·공포 수치와 게이지가 가짜 값으로 흔들리거나 정신력/공포 줄이 뒤바뀜
  - 가짜 버프 아이콘이 뜨고 진짜 디버프(패닉·겁먹음·환각)가 숨겨짐, 목표 문구 오염, 거짓 알림("공포 수치 정상" 등)
  - 화면 효과·심장 소리·"신호 불량" 표시는 정직합니다. 표면으로 나가면 신호가 회복됩니다.
  - 대응: 전파 차단 호일(소모품), 차폐 폰케이스(비품), 의심 갈래 "간파"(주기적으로 진짜 수치가 비침)
  - 교란을 오래 받으면 다음 날까지 휴대폰이 오염되어 화면이 깨지고, 발신 번호 없는 가짜 메시지와 출처 불명 공고(보수 1.6배, 현장 전체 교란)가 들어옵니다.
- **챕터 구조 (5장 · 메인 의뢰 13개)**: 수습 기간 → 신호 불량 → 틈새 → 배양실 → 청명.
  챕터마다 열리는 장소와 위험도, 주당 월세(₩20만→₩48만)가 달라집니다. 메인 의뢰는 앞 의뢰를 끝낸 뒤 2~3일이 지나야 들어오고,
  챕터 첫 의뢰는 랭크(알바 40 / 숙련 150 / 조장 320 / 특별 520)가 필요합니다. 그 사이에는 일반 알바와 심층 탐사로 하루를 채웁니다.
  의뢰가 열리면 의뢰인이 메시지로 연락하고, 새 챕터는 타이틀 카드와 함께 시작합니다. (시뮬레이션 기준 최종장까지 약 30일·30개 현장)
- **주간 루프**: 7일마다 월세, 서경 팀장의 *주간 평가*(이번 주 성공 4건 이상이면 보너스), 그리고 *주간 괴담 동향*
  (알림 폭증·정전 주간·괴담 붐·감사 강화·보수 인상·집단 불안·조용한 주·뒷면 범람 중 하나)이 바뀝니다.
- **근무 수칙 알바 (규칙 괴담)**: "수칙만 지키면 되는" 수상한 야간 꿀알바. 출근하면 수칙표(4~6줄)를 받고,
  02:00~06:00 동안 순찰 지점을 돌며 버팁니다. 수칙 중 일부는 괴담이 끼워 넣은 *거짓 수칙*이며,
  맵 어딘가의 "이전 근무자의 메모"를 찾으면 어느 줄이 거짓인지 알 수 있습니다. (판정은 항상 진짜 수칙 기준)
  - 형광등이 깜빡이면 표면으로 · 발소리가 따라오면 뒤돌아보지 않기 · 이름을 불러도 대답하지 않기 · 종이 울리면 3초 안에 인사(↑)
  - 새벽 3시 정각엔 5초 멈추기 · 빨간 문 열지 않기 · 웃는 손님 공격하지 않기 · 뒷면에 30초 넘게 머무르지 않기
  - 위반하면 공포 급증과 함께 "그것"이 찾아오고, 3번이면 해고. 무위반이면 보수 +30%와 마음 조각.
- **서브 의뢰 13개 (4연작)**: 노을 「새벽마트 수칙」, 집주인 「옥탑방 건물」(월세 할인), 괴담 유튜버 도시탐정 K 「괴담 채널」, 경비 반장 최씨 「한빛타워 야간 경비」(특수 의뢰 4편).
  의뢰가 열리면 의뢰인이 메시지를 보내고, 보상으로 전용 아티팩트(근무 수칙서 원본 — 거짓 수칙 감별 능력 등)를 받습니다.
- **장비 강화**: 무기 강화(+1~+5, 단계당 공격력 +12%), 소모품 가방 확장(최대 소지 +4).
- **생활 압박**: 7일마다 월세(챕터에 따라 ₩200,000 → ₩480,000). 못 내면 빚이 되고 이후 수입에서 절반씩 떼어 갑니다.
- **성장**: 승급(포인트 분배), 비품 구매(무기 8종·장비 6종), 아티팩트 흡수.
- **실패**: 쓰러지면 그날 주운 아티팩트를 모두 잃고 병원비를 냅니다. 오염도가 100이 되면 게임 오버.
- **도감** (휴대폰 앱): 존재 15 · 보스 11 · 아티팩트 37 · 밈 12 · 장소 11, 총 86칸.
  존재는 처음 보면 이름, 한 번 쓰러뜨리면 설명, 열 번 쓰러뜨리면 공략 메모가 열립니다.
  10 / 25 / 40 / 55칸과 도감 완성 때 칭호와 보상(마음 조각, 돈, 소모품)을 받습니다. 도감은 다음 회차로 이어집니다.
- **배경음악**: 장면마다 절차 생성 곡 — 사무소 거리(낮), 옥탑방(밤), 타이틀, 보스전, 진엔딩의 새벽,
  그리고 근무 수칙 알바에서만 나오는 *음이 조금씩 어긋나는 매장 음악*.

## 이야기

13개의 메인 의뢰와 20개의 **진실 조각**(현장 문서·노을과의 거래)으로 청명관리의 정체에 다가갑니다. 폭로 결말에는 진실 조각 15개가 필요합니다.

**결말은 8가지**입니다. 최종장 결재함 앞의 선택지는 지금까지의 진행에 따라 늘어납니다.

| 결말 | 조건 |
|---|---|
| 정규직 전환 / 퇴사 | 언제든 고를 수 있음 |
| 폭로 | 진실 조각 15개 이상 |
| 동화 | 오염도 60 이상 |
| 오염 100% | 오염도가 끝까지 차오름 (게임 오버) |
| 동반 퇴사 | 노을 연작 「마지막 근무」 완료 — 최종전에서 노을이 회복과 교란 차단으로 돕는다 |
| 생방송 | 도시탐정 K 연작 「마지막 방송」 완료 — 최종전에서 시청자 응원이 희망이 된다 |
| **모두의 퇴근 (TRUE)** | 2회차 이상 · 재계약 문서 4종 · 진실 20개 이상 · 노을과 K 연작 완료 — 청명 뒤에 숨은 최종 보스 「무명」 |

**재계약 (2회차)**: 어떤 결말이든 본 뒤 "재계약"으로 다음 회차를 시작할 수 있습니다.
마음 지도·무기와 강화·가방·장비·도감을 이어받고(돈은 일부만), 뒷면의 존재는 회차마다 단단해지며(체력 +20%/회차, 최대 3회차) 보수도 오릅니다.
2회차부터는 프롤로그와 일부 의뢰의 대사가 달라지고, 메인 의뢰 현장 네 곳에 **재계약 전용 문서**(진실 조각 21~24)가 숨어 있습니다.
타이틀의 "엔딩 기록"에서 아직 보지 못한 결말의 힌트를 볼 수 있습니다.

## 구조

```
index.html            진입점 (스크립트 로드 순서 정의)
css/style.css         레이아웃, 터치 버튼, 폰트
assets/fonts/         Galmuri 도트 폰트 (SIL OFL 1.1, OFL-Galmuri.txt 참고)
js/engine/            util(난수·한글 조사), settings(환경 설정), input(키보드·게임패드·터치), audio(WebAudio 절차 사운드·음악 시퀀서), gfx(캔버스·도트 도구), uikit(UI 부품)
js/data/              content(테마·적·보스·아티팩트·아이템), story(대사·문서·엔딩), skills(스킬트리·상태 효과), sprites(절차적 도트 스프라이트)
js/game/              state(저장·하루 진행), achieve(업적·외형), level(이중 레이어·충돌·튜토리얼 맵), rooms(방 조각 맵 생성·도달 검사), entities(플레이어·적),
                      boss(보스 패턴), ui(대화·메뉴·환경 설정), skilltree(마음 지도 화면), codex(도감), mission(임무 씬),
                      special(정전 복구·암흑 작업·배웅·추격), hub(동네 허브), scenes(타이틀·결과·엔딩·회차)
js/main.js            고정 60fps 루프, 씬/모달 관리
```

모든 그래픽(캐릭터, 적, 보스, 타일, 소품, 아이콘)과 사운드는 코드로 생성됩니다. UI는 `js/engine/uikit.js`의 공용 부품(카드, 키캡 안내, 슬림 게이지, 상태 아이콘, 휴대폰 프레임)으로 그립니다. 진행 상황은 브라우저 `localStorage`에 저장됩니다.
